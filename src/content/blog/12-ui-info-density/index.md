我基于大模型做了很多 UI 卡片、信息卡、PDF 等，把高密度信息结构化，或者把论文文章组成知识图谱。所有这些 UI 形式都是为了方便别人理解，而不是为了方便自己理解。

对自己来说，信息密度是越高越好。但对别人来说，目标是更容易理解。不同的信息给不同的人看，模式是不一样的。UI 的底层逻辑是不同的。

---

给自己是信息密度越高越好，给别人是认知负担越低越好。这两件事不是同一件事，甚至经常背道而驰。

一份结构精密的知识图谱，自己存下来复习效率极高。但扔给一个没看过原论文的人，对方只会觉得信息过载而无法消化。反过来说，一张极度通俗、充满图示和类比的卡片，能让外行快速建立感知，但它对自己来说信息折损太多，根本不值得保存。

问题出在：我们经常用「给自己」的标准去评判「给别人」的 UI，或者反过来。真正的问题不是「信息密度够不够高」，而是「这个 UI 是为了谁的什么目的而存在」。

换句话说，UI 的底层逻辑不是由信息本身决定，而是由「谁在看」和「要达成什么」来决定。这个认知转变，是从「记录」到「传播」的本质跨越。
